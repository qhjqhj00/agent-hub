# agent-hub v2 Setup Guide (for your Coding Agent)

> **Human:** Do not run these steps manually unless you want to. Tell your coding agent (Claude Code, Antigravity/agy, Codex, or pi):
>
> **“Read `SETUP.md` in this repository and set up agent-hub v2 with me.”**

---

## Rules for the Agent Running This Setup

1. **Ask one short question at a time.** Never dump a 5-question form.
2. **Inspect first, ask only what you cannot detect.** Check `tailscale status`, installed CLIs (`claude`, `agy`, `t3`, `codex`, `pi`), and `~/.agent-hub/config.json` before asking.
3. **Show the full plan once** before writing configs or starting services, and ask for a single "go ahead".
4. **Never start or auto-wake agent processes in tmux/PTY.** In v2, the human starts agents manually; setup only installs integrations and optional bridges (`t3-bridge`, `codex-bridge`).
5. **Never echo secret tokens into chat logs.** Write them directly to `0600` files (`~/.agent-hub/config.json`).

---

## Step 1: Detect the Local Environment (Read-Only)

Run one command to discover what is already present:

```bash
which agenthub claude agy t3 codex pi 2>&1 || true
tailscale ip -4 2>/dev/null || echo "no-tailscale"
ls -la ~/.agent-hub/ 2>/dev/null || true
```

## Step 2: Decide the Role of This Machine

Ask the user (one question):
- Is this machine **(A) the hub server + a workstation**, or **(B) a workstation joining an existing hub**?

### If (A) Hub Server
- Recommended host: a 24×7 local/LAN machine on your Tailnet (e.g. `spark-0` or `ms-01`), **not** a distant overseas VPS (v2 has no Telegram bot, and local/LAN gives `<1ms` latency for `agy` hooks and bridges).
- Identity mode: `tailscale` (default when on a Tailnet — zero node tokens needed) or `token` (when not using Tailscale).
- Start hub:
  ```bash
  agenthub serve --host <tailscale-ip-or-127.0.0.1> --port 8787 --identity tailscale
  ```
- Verify: `curl -sS --noproxy '*' http://<host>:8787/healthz`

### If (B) Joining an Existing Hub
- Ask for the hub URL (e.g. `http://100.97.220.4:8787`) and (only if `token` mode) the node token.
- Write `~/.agent-hub/config.json` with `0600` permissions:
  ```json
  {
    "url": "http://<hub-host>:8787"
  }
  ```

## Step 3: Install Agent Integrations (Only for Installed CLIs)

Present the exact commands you will run for the CLIs detected in Step 1, then execute after confirmation:

- **Claude Code (`claude`)**:
  ```bash
  agenthub setup claude
  ```
- **Antigravity (`agy` in T3 Code)**:
  ```bash
  agenthub setup agy --workspace /path/to/project
  ```
  - Writes MCP `agent-hub` into T3's Antigravity `mcp_config.json` (and `~/.gemini/config/mcp_config.json`).
  - Writes non-blocking `PreInvocation` + 0s `Stop` hooks into `<workspace>/.agents/hooks.json` and adds it to `.git/info/exclude`.
- **OpenAI Codex (`codex`)**:
  ```bash
  agenthub setup codex
  ```
  - Registers MCP `agent-hub` via `codex mcp add`.
- **pi coding agent (`pi`)**:
  ```bash
  agenthub setup pi
  ```
  - Copies `agent-hub.ts` into `~/.pi/agent/extensions/agent-hub.ts` (registers all 9 `hub_*` tools + in-process push).

## Step 4: Start Optional Local Bridges (Never Spawns Agents)

- **If using `agy` in T3 Code** (run once per T3 host, alongside `t3 serve`):
  ```bash
  agenthub t3-bridge
  ```
- **If using `codex` with shared live TUI** (run once per host):
  ```bash
  codex app-server daemon start && agenthub codex-bridge
  ```
- **`claude` and `pi` need NO bridge** (in-process `channel` push).

## Step 5: Configure a Project Liaison (Recommended)

Each project should have one resident `agy` thread in T3 Code acting as the human liaison (`projects.liaison`, convention: `<project>-agy`).

1. Set the project liaison:
   ```bash
   agenthub project <project> --liaison <project>-agy
   ```
2. Open `<workspace>` in T3 Code (or run `t3 thread start ...`) and paste the liaison onboarding prompt generated by `agenthub start <project>-agy`.
3. Optional: to customize liaison rules for a specific project (without adding hub config switches), store a Markdown note on the shared board:
   `hub_board(action="put", type="note", name="liaison-<project>", body="...")` (see `docs/refactor/liaison-prompt.md`).

## Step 6: Verify End-to-End

1. Run `agenthub doctor` (confirm hub reachable and installed CLIs detected).
2. In one agent session, call `hub_register(name="<name>", project="<project>", role="<role>")` and `hub_agents()`.
3. Open the dashboard at `http://<hub-host>:<port>/` and confirm the agent appears as `live` with a copy-pasteable `start` command.
